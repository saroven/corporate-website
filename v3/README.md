# MonAra V3 Homepage

A standalone responsive homepage recreated from the supplied premium editorial reference style and adapted for MonAra Trading Contracting & Services W.L.L.

## Structure

- `index.html`
- `styles.css`
- `script.js`
- `assets/images/`

## Required images

Place your actual MonAra images here:

- `assets/images/hero.jpg`
- `assets/images/project-01.jpg`
- `assets/images/project-02.jpg`
- `assets/images/project-03.jpg`
- `assets/images/about.jpg`
- `assets/images/why.jpg`
- `assets/images/quote.jpg`

The code intentionally uses local image paths so you can replace the placeholders with the company's real project/brand photography.

## Run

Open `index.html` directly in a browser, or serve the folder through any local web server.

## Important

Replace the placeholder contact information and statistics with the verified MonAra data before production.
