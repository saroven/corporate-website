# MonAra Corporate Website

Standalone bilingual corporate homepage built with semantic HTML, custom CSS, Tailwind CSS, and vanilla JavaScript.

## Development

```bash
npm install
npm run watch
```

Open `index.html` through a local web server while developing.

## Production build

```bash
npm run build
```

The compiled Tailwind stylesheet is written to `assets/css/tailwind.css`.

## Structure

- `index.html` — homepage markup and English/Arabic content hooks
- `assets/css/styles.css` — component and responsive styling
- `assets/css/tailwind.css` — compiled Tailwind output
- `assets/js/main.js` — language switching, navigation, reveal effects, and form validation
- `src/tailwind.css` — Tailwind source entry

The company details, project names, experience value, and client marks are demonstration content pending verification.
